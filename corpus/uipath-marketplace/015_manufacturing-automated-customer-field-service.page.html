    Summary

    The following package is a Solution Accelerator that can be used as a starting point for automating the support processes related to Customer and Field Service in the Manufacturing Industry.

    Overview

    The solution provides automation for customer and field service in manufacturing environments by connecting to different applications such as: ERPs, CRMs and various Service Management tools, providing seamless data flow across systems.

    An aditional process within the solution uses UiPath Document Understanding to extract any missing information, while the final part of the Solution Accelerator uses AI components distribuited across the data flow to improve the experience of customers and field technicians. 

    The starting point of the Automation with the Solution Accelerator is the retrieval of emails containing product information, either text or image, relevant to the request being performed.

    Data is extracted from Salesforce using an unique identifier retrieved from the email, alongside with a sentiment analysis, offering information on the tone of the message. Utilizing product identification, the system automatically retrieves equipment details from SAP Plant Maintenance Module.

    At the same time an incident ticket is generated within ServiceNow. The response to the request is generated using Azure Open AI, further enhancing the communication efficiency.

    The goal of the UiPath Solution Accelerator is to serve as a solid framework for automating processes involving support and customer relationship within the Manufacturing Industry.

    Features

    1. Email Processing.
    2. Automated customer information crossmatching with Salesforce.
    3. Ticket priority value suggestion, based on Email Sentiment Analysis.
    4. Email attachment data extraction.
    5. Extra crossmatching capabilities for tools, SOP, spare parts, with SAP.
    6. Automated data consolidation from all systems sources + Automated ServiceNow ticket creation.
    7. Auto-fill option during ticket configuration (using Azure OpenAI).
