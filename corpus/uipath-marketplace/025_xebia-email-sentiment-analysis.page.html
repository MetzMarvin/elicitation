    Xebia - Email Sentiment Analysis

    by Xebia

    ★★★★★ | Solution | <100
    Overview Reviews Q&A

    Summary

    The component is useful when a company wants to analyse their performance, and what is the impact of their work each month based on feedback emails

    Overview

    Problem Statement:

    To minimize the manual work and increase process efficiency, we propose Sentiment Analysis while automating the process with the help of RPA (Robotic Process Automation). This system will be capable of fetching emails, doing analytics and sending feedback to customer according to the sentiment from email.

    Steps:

    1. Reads Email from Outlook
    2. Copies the Data from the Email Body as a string to the Python Library (Machine Learning Model).
    3. Machine Learning Model gives the solution in the form of True and False (Whether the mail is positive or negative in nature.)
    4. After that we can do the corresponding work, for example if the response if positive the mail BOT should send a Thank you mail to the Customer.
    5. In case of negative review, the BOT will send an Apology mail to the customer plus will highlight the matter to the assigned authority.

    Features

    Added Business Value Proposed solution is capable of delivering: • 8x time faster execution then existing system. • Reduction of 9 FTE. • Improved effectiveness and efficiency with accuracy.

    Additional Information

    Dependencies

    Python 32 bit Python libraries used: i. Library (Scikit- Learn) ii. Pickle Library iii. JSON Library UiPath 2019.4.2
