    Summary

    The contents of this solution can be seen as a technical blueprint, a starting point for a complete Know Your Customer Processing Automation, that is meant to be modified, refactored and customized.

    Overview

    This package is a Solution Accelerator that can be used as a starting point for Know Your Customer Processing. Know Your Customer Processing is a mandatory process of identifying and verifying a client’s identity through submitted documents. 

    This process uses Out-of-the-box Pre-trained ML Package Models for Passports, ID Cards, Utility Bills, Bank Statements, and 4056T Forms as defined in documentation located here. For specific taxonomy and extracted fields, please refer to the documentation. 

    The Solution Accelerator uses the public endpoints defined in documentation. If further fields are needed or you would rather not use the public end point, the OOTB model can be deployed in AI Center and then trained using a process defined in documentation here.

    Features

    1. Retrieving KYC Documents from a Data Source (like an email inbox, a network drive, or a third-party application).
    2. Digitize KYC Documents, classify, extract document details, running business rule validations.
    3. Process document validations.
