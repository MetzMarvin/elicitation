    UiPath Cards Dispute Classification for Banks

    by Internal Labs

    ★★★★★ | Solution | <100
    Overview Reviews Q&A

    Summary

    This accelerator automates the classification of card disputes into standard codes based on the classification types provided by card providers.

    Overview

    Dispute resolution forms a key process in the Cards life cycle. As part of this, process dispute requests are registered by customers through different channels. 

    For successful dispute resolution, a key process step to be done during the initial phase of request receipt is identifying the dispute type. All major card providers (Visa/Mastercard/Amex) require Issuing banks to classify the dispute requests. 

    Each of these card providers have standard classification types against which issuing banks need to map the dispute requests. Currently this dispute classification process is either a manual or semi-manual process in most of the banks. An agent from issuing bank is trained to classify the disputes correctly against the reason codes. Next course of action on the dispute is taken based on this classification. 

    This accelerator helps in providing a correct classification of dispute type. The model works by extracting relevant content from the dispute requests and classification of the requests into standard dispute types. The model uses pre-trained Machine Learning models using NLP algorithms. 

    After the classification of a dispute, the workflow updates the case in the case management tool for further action to be taken. This accelerator improves both SLAs for resolution and also greatly increases classification accuracy.
