AI Task

Contents

  • AI Task

    • Attributes and Form

    • Usage Examples

  • Comparing Contract Versions

  • Automatic Text Generation in a Commercial Proposal

A task responsible for calling an AI based on a specified prompt. Subsequently, depending on business requirements, it can perform any action BPMN allows: send tasks, notifications, generate documents, and so on.

Attributes and Form

Specify Name.
Preparing Data for AI Call

Script
JavaScript executed before the AI request.
Used to prepare data or include additional documents in the context.
To add to the context:
let contracts = ["emodel/ecos-contract@contract1", "emodel/ecos-contract@contract2"];
execution.setVariable("aiRecordsContext", DataValue.of(contracts));
aiRecordsContext — an array of references to documents available to the AI. Must be wrapped in a DataValue.
Forming the AI Request

Include Document in Context
Adds the current business process document to the AI request context.
The AI will be able to consider its data when forming a response.

Request Text
The prompt sent to the AI.
Process variables can be inserted using ${someVariable}.
Variables are resolved in the following order: first they are looked up in process variables (execution variables), then, if not found, they are loaded from the document attributes via RecordsService.
Example:
Подготовь черновик письма клиенту по поводу просроченного платежа.
Контактное лицо: ${clientName}, сумма долга: ${debtAmount}, срок просрочки: ${daysOverdue} дней.
Working with the AI Result
The AI always returns text.
By default, the response result is always saved in the process variable aiResponse. This variable can be used in scripts.

Save Result to Document Attribute
The AI response will be written to the specified attribute of the document associated with the business process.

Script
JavaScript executed after receiving the response from the AI.
The request result is available in the variable aiResponse.
Asynchrony Settings:
- Асинхронно “перед” — исполнение доходит до точки перед блоком, транзакция комитится и дальнейшее выполнение ставится в очередь, которую разбирает уже джоба.
- Асинхронно “после” — исполнение доходит до точки после блока, транзакция комитится и дальнейшее выполнение ставится в очередь, которую разбирает уже джоба.
See more about asynchronous tasks

Usage Examples

Let’s consider 2 examples of embedding an AI task into business processes.

Comparing Contract Versions

In the ‘Contracts’ module, employees can upload different contract versions and make edits during the approval process.

Consider a small business process that reacts to changes in contract content and adds a comment to the contract card listing key changes and conclusions.

A signal is configured for content changes, then an AI task is launched. In the “Request Text” field, we ask, similar to working with the AI assistant, what the latest changes to the contract content were, and request the response in HTML format.

In the “Script” field, we will create a comment for the contract listing the changes:

const comment = Records.get('emodel/comment@');

comment.att('text', aiResponse);
comment.att('record', documentRef);

comment.save();

Automatic Text Generation in a Commercial Proposal

In the CRM module, automatic text generation in a commercial proposal can be implemented. Download process

When a deal transitions to the ‘Commercial Proposal Preparation’ status, an AI task is launched that populates contextual data. In the preprocessing stage, we extract the client’s name, legal entity, and list of products and services, and use this data further in the prompt.

After this, a script task is launched, which will generate the commercial proposal template.

The text will be generated based on the client’s information, the supplier, and the products and services selected in the card.
