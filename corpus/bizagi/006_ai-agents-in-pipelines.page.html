Execute AI Agents in Pipelines

Overview

This article shows you how to configure AI Agents within Pipelines in Bizagi, allowing you to seamlessly integrate AI into any pipeline step. This enhancement increases the flexibility and power of pipelines, enabling you to incorporate AI-driven tasks throughout your workflows.

 

Adding an Agent to a Pipeline

1.Log into Bizagi Studio.

2.Select a Project.

3.From the Wizard, choose the Process where you want to use one or more AI Agents in Pipelines.

4.Navigate to Step 4. Business Rules - Activity Actions in the Wizard.

 

 

5.Double-click the AI Task where you want to put the Pipeline and add a new Pipeline.

 

 

6.Create or edit a Pipeline and add an AI Agent within its configuration.

 

 

Remember that you can also create/edit pipelines from the Expert View.

 

7.Select the AI Agent and configure data mappings accordingly.

 

 

 

8.Put your AI Agent(s) to the test.

 

Keep in mind that you can add multiple AI Agents to the same pipeline.

 

Important considerations

AI Agents usually run only on IA tasks. With this update, they can now run on other tasks using Pipelines. However, this is not recommended, as IA tasks may need asynchronous execution due to longer processing times. If you try to set up a pipeline with AI Agents on non-IA tasks, you will get a warning about possible usability issues in the Work portal.
